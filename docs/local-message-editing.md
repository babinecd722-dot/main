# Где доступно локальное редактирование

«Изменить локально» доступно в обычном контексте чата для текстовых сообщений,
структурированного текста и подписей к фотографиям и файлам, включая обычные видео,
GIF и аудио. Редактирование входящих и старых сообщений остаётся локальной функцией
и не зависит от серверных прав на изменение.

Подарки, Premium, переводы звёзд и GRAM, оплаты, звонки и остальные служебные
карточки не редактируются этим действием. Оно также не показывается у стикеров,
видеосообщений, опросов, контактов, геопозиций, игральных костей, игр, историй,
розыгрышей, списков задач, истёкшего и неизвестного содержимого. При появлении нового
типа медиа он остаётся на штатном пути взаимодействия, пока явно не поддержан.

Меню исключено из встроенных представлений, списка закреплённых сообщений,
заголовка ветки ответов и старого мигрированного чата. Единое правило
`AorusLocalMessageEditing.canEdit` применяется также перед сохранением из редактора.
Посты «Стены» сохраняют собственные действия с локальной лентой вместо редактора чата.
Для обычного сообщения, текст которого был очищен локально, действие «Оригинал»
сохраняется. Наличие старой записи локального изменения не включает редактор
для специальной карточки.
