# Оформление

## Акцентная тема

У AorusGram одна акцентная тема в двух вариантах: светлом и тёмном. Обе используют
фиолетовый акцент `0x9b4dff`. Исходящие сообщения окрашены градиентом от `0x9b4dff`
до `0x7c30d8`, текст в них белый.

- Светлый вариант построен на стандартной теме Telegram «Классическая». Акцент применяет
  механизм Telegram, через который пользователь выбирает цвет акцента. Этим цветом
  окрашиваются кнопки, ссылки, переключатели, отметки и графики.
- Тёмный вариант построен на теме «Ночная». Кнопки в ней белые, как в Telegram. Таббар и
  поиск используют оттенки `0x202022` и `0x2c2c2e`.

В обоих вариантах выбранная вкладка таббара акцентная, остальные серые. Стеклянный
таббар Telegram 13 окрашивает иконки цветом подписей вкладок, поэтому серый задан и для
иконок, и для подписей. В светлом варианте это серый иконок «Классической» `0x959595`.

Обычные темы Telegram остаются без изменений: «День», «Ночная с акцентом» и облачные.
Если пользователь выбрал собственный акцент для «Классической» или «Ночной», эта тема
тоже отображается как в Telegram.

## Переключение

Какой вариант показан, определяет «Ночной режим» Telegram. По умолчанию выбрано
значение «Системный», как в Telegram, поэтому приложение светлое при светлом
оформлении телефона и тёмное при тёмном. Остальные значения ночного режима работают
как в Telegram: «Выключен», «По расписанию» и «По яркости».

Telegram узнаёт оформление телефона из корневого контроллера окна. Если оформление
поменялось, пока приложение было в фоне, тема переключается при возвращении в
приложение. Стиль оформления окна не переопределяется: в Telegram эти два блока
закомментированы и остаются такими. Системные контролы на экранах получают стиль
темы через каждый контроллер Display. Системные окна, открытые с экрана, получают стиль
темы этого экрана: алерты, меню «Поделиться», выбор файлов и фотографий.

Предыдущие сборки закрепляли «Выключен», чтобы приложение оставалось тёмным. При
первом запуске новой сборки ночной режим один раз переводится на «Системный». Обои,
выбранные в прежнем тёмном оформлении, переносятся в слот «Ночной», из которого они
теперь показываются. Перенос выполняет только приложение, расширения его не делают.
Признак выполненного переноса хранится в `aorusgram_appearance_follows_system`.

Превью противоположного варианта тоже показывают акцентную тему:

- переключатель «день/ночь» в теме чата;
- галерея обоев;
- ночное превью в настройках оформления.

## Запуск и экран приветствия

Экран запуска и окно до загрузки темы используют системный фон: белый при светлом
оформлении и чёрный при тёмном.

На экране приветствия вместо сферы и самолёта Telegram показан логотип AorusGram.
OpenGL-сцена Telegram не создаётся и не отрисовывается. Представление, которое
анимирует контроллер, содержит только логотип. Цикл отрисовки 60 кадров в секунду
не запускается, в том числе после возвращения из фона.

Логотип вырезан из иконки приложения и не имеет фона. Для каждого фона экрана есть
свой вариант:

- Тёмный фон: каждый пиксель иконки становится своим цветом с прозрачностью по яркости.
  На чёрном фоне результат совпадает с иконкой, расхождение не больше 3 из 255.
- Светлый фон: буква тёмная, а фиолетовые элементы и их свечение сохраняются.

Оба файла создаёт `scripts/intro_logo_generate.py` из
`patches/appicon/AppIconLLC.appiconset/icon1024.png`.

## Экраны AorusGram

Экраны AorusGram берут цвета из текущей темы. Экраны с собственным тёмным дизайном
имеют светлый вариант на цветах сгруппированных списков светлой темы:

- состояние ATunnel и диагностика;
- окно «Голос в текст» и карточка диктовки;
- инструменты редактора масок.

Блик на ленте действий ИИ-компаньона в тёмном варианте — белые буквы в фиолетовом
свечении. В светлом буквы под бликом окрашены акцентом и светятся тем же цветом.

Страница «Подробнее» из профиля в «Интерфейсе 2.0» продолжает цвет страницы профиля.
Цвет заголовка, кнопки «Назад», стеклянных кнопок и строки состояния выбирается по
яркости этой страницы, а не по теме приложения.

## Проверки

`scripts/verify_aorus_branding.py` проверяет на внедрённом дереве:

- применение акцентной темы на первом кадре и в работающей теме;
- перенос настроек;
- отсутствие синего акцента Telegram у «Ночной»;
- значение ночного режима «Системный» по умолчанию;
- превью;
- экран запуска;
- логотип на экране приветствия без OpenGL-сцены.

`scripts/client_lifecycle_check.py` проверяет цвета запуска.
